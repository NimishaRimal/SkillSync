# SkillSync – Student Skill Exchange and Collaborative Study Platform

## About the Project
SkillSync is a student-focused platform where students can exchange skills, find learning partners, and collaborate on study activities.

## Features
- Student registration and login
- Student profiles
- Search for skills to learn
- Add skills to teach or learn
- Send and manage skill requests
- Schedule study sessions
- Mark sessions as completed
- Rate and review study partners

## Technologies Used
- HTML
- CSS
- JavaScript
- Bootstrap
- PHP
- MySQL

## Installation and Setup
1. Install XAMPP.
2. Clone or download this repository into the `htdocs` folder.
3. Create a MySQL database named `skillsync_db`.
4. Import or create the required database tables.
5. Configure your local database connection in `db.php`.
6. Start Apache and MySQL from the XAMPP Control Panel.
7. Open `http://localhost/SkillSync/` in your browser.

**Note:** Database configuration and table setup may need to be completed before the application can run. Never upload database passwords or other secret credentials to a public repository.
